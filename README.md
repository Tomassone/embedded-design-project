## How to use the serial communication console: 

+ use this software: minicom (run it from the terminal emulator)
+ but before doing that it is necessary to set it up with the command: sudo minicom -s
+ remember to select the /dev/ttyS0 interface for RS232 communication
+ the key combination CTRL + A is used to access all the commands (CTRL + A + H to show all of them)
